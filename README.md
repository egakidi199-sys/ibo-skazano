# Ибо сказано

Веб-приложение: описываете ситуацию и тезис, выбираете «Подтвердить / Опровергнуть / Обе стороны» — и получаете подлинную цитату из Священного Писания с точной ссылкой и коротким пояснением.

- **Корпус:** Синодальный перевод, 39 книг Ветхого Завета и четыре Евангелия.
- **Принцип:** искусственный интеллект предлагает только ссылки; текст цитаты всегда берётся дословно из корпуса, несуществующие ссылки отбрасываются.
- **Без ИИ:** при недоступности модели работает упрощённый подбор по темам и ключевым словам.

## Разработка

```bash
npm install
npm run dev        # интерфейс без сервера (упрощённый подбор)
npm run dev:full   # полный стек с серверной функцией (нужен .dev.vars по образцу .dev.vars.example)
npm test
```

Требования и план — в `openspec/changes/ibo-skazano-mvp/`.
