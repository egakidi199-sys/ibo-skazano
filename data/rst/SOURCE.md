# Источник текста

- **Перевод:** Синодальный перевод Библии (1876), общественное достояние.
- **Репозиторий:** https://github.com/bibleonline/rst (исходник текста bible.ru).
- **Каталог:** `parsed/` — полное издание из 77 книг с синодальной нумерацией.
- **Коммит:** `2de3062388a2c067bc602399bda7149eec918ceb` (2026-04-11).
- **Происхождение по README репозитория:** Logos Bible Software, «Russian Synodal Bible Translation», Российское Библейское общество, 1995, ISBN 978-5-85524-328-4, Copyright: Public Domain. Вычитан по печатным изданиям РБО 2002 (ISBN 978-5-85524-150-1) и МП РПЦ 2016 (ISBN 978-5-88017-237-5).
- **Лицензия репозитория:** файла LICENSE нет; сам текст перевода — общественное достояние.
- **Выбрано подмножество:** 39 книг Ветхого Завета + Евангелия от Матфея, Марка, Луки и Иоанна (43 файла). Неканонические книги и остальные книги Нового Завета не копировались.

Файлы лежат без изменений (байт в байт как на указанном коммите). Любая нормализация делается скриптом `scripts/build-corpus.mjs`, а не правкой этих файлов. Обновление источника — осознанное: скачать файлы с нового коммита, обновить этот документ и прогнать `npm run build:corpus` (эталоны).
